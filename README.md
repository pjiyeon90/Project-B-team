# 첫번째 팀프로젝트 : 해양생물연구센터 반응형 웹
##### 한화해양생물연구센터를 기반으로 리뉴얼 해 반응형 웹 사이트를 구현하였습니다.

### 🌈 프로젝트 링크
###### <https://pjiyeon90.github.io/Project-B-team/>

### 💡 프로젝트소개
###### <https://www.canva.com/design/DAGPlU0-6ow/jtn9ibfQwajWRzBjK4CM8g/edit?utm_content=DAGPlU0-6ow&utm_campaign=designshare&utm_medium=link2&utm_source=sharebutton>


한화에서 운영하는 해양생물연구 사이트로 상업적으로 만든 사이트가 아니기에
관심도가 낮은 만큼 오래된 상태로 방치되어 노후화되고 옛스러운 디자인에 고착되어있어
리뉴얼을 결정하였습니다. 

연구적인 사이트로 사용되긴 하지만 사용자가 사용하기 쉽고 정보를 한눈에 볼 수 있도록
디자인 방향 및 리뉴얼 방향성을 잡고 진행하였습니다.
